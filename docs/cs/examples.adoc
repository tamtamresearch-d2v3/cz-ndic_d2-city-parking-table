Obálka a hlavička::
Kořen `d2:payload` typu `prk:ParkingTablePublication` s atributy `@profileName` a `@profileVersion`,
`publicationTime` a `publicationCreator`. `feedType` odkazuje na distribuci (zdroj dat).

Parkoviště::
* Každé parkoviště má identifikátor GUID, název a úroveň 0 (`layer`, `type` = `place`).
* Parkoviště P+R mají způsob využití P+R (`operatingPattern` typu `prk:UsageScenario` s `type` =
  `parkAndRide`).
* Kapacitu, provozovatele ani provozní dobu data zatím neuvádějí.

Poloha::
* Parkoviště je bod (`coordinatesForDisplay`) na úseku komunikace parkoviště. Úsek popisuje OpenLR,
  síť Global Network a průběh polohy `gmlLineString`.
* U většiny parkovišť stačí jeden úsek sítě Global Network. Bod parkoviště P+R Opatov leží na hranici
  dvou úseků, poloha proto uvádí oba.
* Parkoviště Muzeum má navíc polohu ALERT-C.
